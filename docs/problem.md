# Problem Definition

## Project

Search Engine from Scratch

## Investigation question

How do retrieval architecture and ranking choices change correctness, relevance, latency, memory, and index cost on a controlled corpus?

## What the system must eventually do

Build a controlled search system whose mechanisms can be inspected, tested, measured, compared, and broken.

## Scope

The project begins with search foundations and grows incrementally through indexing, retrieval, scoring, evaluation, performance, failure analysis, semantic retrieval, scaling, and comparative investigation.
